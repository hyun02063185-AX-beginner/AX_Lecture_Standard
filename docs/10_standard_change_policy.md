# Standard Change Policy

Standard는 특정 강의의 일회성 요구를 즉시 흡수하지 않는다. 변경을 제안할 때 아래 순서로 판단한다.

1. 이것은 강의별 Customization인가?
2. 반복되는 요구인가?
3. Canonical Standard 변경이 실제로 필요한가?
4. 근거와 반례를 Decision Record에 남겼는가?
5. Standard version을 올렸는가?

새 규칙은 적용 사례의 성공·실패, QA, rehearsal 같은 재현 가능한 근거를 갖춰야 한다. Source Asset 또는 Application의 판단은 Reference가 될 수 있지만, 별도 versioned change 없이는 Canonical을 바꾸지 않는다.

결정의 현재 요약은 [Decision History Summary](../references/decision_history_summary.md)를, 적용 이력은 [Application Registry](11_application_registry.md)를 참조한다.
