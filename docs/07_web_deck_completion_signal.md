# Web Deck Completion Signal

Web Deck의 종료는 게임 보상이 아니라 발표의 의미를 닫는 신호다.

| Variant | 기본 Profile | 역할 |
|---|---|---|
| A — Simple | 30 | 짧고 명확한 마무리 |
| B — Callback | 60 | Opening material을 회수하는 마무리 |
| C — Callback + Action | 90 / 120 | callback에 다음 행동 또는 다음 단계를 더한 마무리 |

모든 profile은 권장값이며, 콘텐츠의 성격에 따라 변경할 수 있다. 단 B와 C는 [Authoring Guide](05_web_deck_authoring_guide.md)의 Opening → Closing Callback 규칙을 충족해야 한다.

## Web Deck에서 기본 제외하는 종료 방식

- XP
- Rank
- Unlock
- Confetti
- “수료 완료”

이는 과정형 Experience에서 의미가 있을 수 있는 Optional 기능이며, 기본 Web Deck completion으로 사용하지 않는다.
