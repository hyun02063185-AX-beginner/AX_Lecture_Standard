# Web Deck Time Profiles

Time Profile은 engine의 자동 설정이 아니라 저작·rehearsal을 위한 권장 프레임이다. 실제 rehearsal 결과가 우선한다.

| Profile | Typical Sections | Typical Slides | Navigator | Resume | Completion |
|---|---:|---:|---|---|---|
| 30 | 1–2 | 약 6–8 | none | off | A |
| 60 | 1–2 | 약 10–14 | none | off | B |
| 90 | 3–4 | 약 18–26 | optional fan | optional | C |
| 120 | 5–7 | 약 26–34 + activity | fan optional | recommended / optional | C |

모든 수치는 Recommendation이다. 청중, demo, interaction, practice, break와 콘텐츠 보존 이유가 slide 수에 영향을 준다. 따라서 **Slide Count ≠ Time**이다.

## Application example

AI Attitude는 AX Web Deck 60의 Golden Application이다. 12개 lesson의 의미 보존과 발표 호흡 때문에 19 slides를 유지한다. 이는 60분 profile의 숫자 권장을 무효화하는 예외가 아니라, rehearsal과 콘텐츠 근거가 권장값보다 우선한다는 사례다. 상세는 [Application Registry](11_application_registry.md)를 참조한다.

## Navigator와 Resume

Card Fan과 Resume은 시간만으로 자동 적용하지 않는다. 아래 판단을 함께 사용한다.

- section 수와 독립성
- presenter의 jump 필요성
- overview와 비선형 이동의 가치
- 청중·강의의 재진입 요구

세부 분류는 [AX Web Deck Standard](03_ax_web_deck_standard_v0.1.md)를 따른다.
