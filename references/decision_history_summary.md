# Decision History Summary

이 기록은 과거 Sprint를 복원하는 문서가 아니라, 현재 Canonical을 설명하는 결정 요약이다.

| Decision | Canonical consequence |
|---|---|
| AI Attitude는 Source Asset이 아니라 Application | 적용 사례는 Standard와 분리해 기록한다. |
| AX Lecture Experience / AX Web Deck 분리 | 목적과 구조가 다른 두 Family를 유지한다. |
| Editorial / News는 Skin | Design DNA나 architecture로 승격하지 않는다. |
| Room / Box는 Web Deck에서 제거 | Experience 전용 구조·언어로 취급한다. |
| Card Fan = LONG-DECK OPTIONAL | 시간만으로 자동 적용하지 않는다. |
| Resume = LONG-DECK OPTIONAL | 명시적 option으로만 사용한다. |
| 30 / 60 / 90 / 120 = Profile | 권장값이며 rehearsal이 우선한다. |
| Completion A / B / C | Simple / Callback / Callback + Action으로 구분한다. |
| Slide Count ≠ Time | lecture, demo, interaction, practice, break를 분리해 계획한다. |
| AI Attitude Direction A = first Golden Application | Direction B는 제한된 evidence language만 제공한다. |

표준 변경은 [Standard Change Policy](../docs/10_standard_change_policy.md)의 versioned 절차를 따라야 한다.
