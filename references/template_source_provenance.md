# Template Source Provenance

## Web Deck Engine

Primary reference: **AI Attitude**. Reused decisions are slide-oriented navigation, progress, keyboard/swipe input, fullscreen request handling, chrome auto-hide, section-aware data, and safe rendering. AI Attitude content, assets, amber identity, opening/closing copy, and evidence-marker rules are excluded.

## Experience Engine

Primary reference: **AX Lecture**. Reused decisions are Hub-oriented entry, lesson navigation, progress awareness, spatial composition, and state boundaries.

Secondary references: **AI FirstStep** validates an optional participant-led Practice pattern and light learning Skin; **Codyssey Lecture** supplies counterexamples for unsafe content mapping and `undefined` rendering defects.

## Important

Reference projects are not runtime dependencies. The Template implementations are newly written, framework-free, and contain no source-project path, asset, curriculum, or project-specific state key.
